================================================================================
  url_for() の使い方
  - Blueprint のルートにアクセスする方法 -
================================================================================

質問:
  profile_bp = Blueprint('profile', __name__, url_prefix='/api')
  があって
  @profile_bp.route('/user/profile', methods=['GET'])
  にアクセスしたい場合
  profile_bp.profile とすると アクセスできる？


回答:
  ❌ profile_bp.profile は間違いです
  ✅ url_for('profile.関数名') が正しいです

  重要: ルートのパス('/user/profile')ではなく、
        関数名を使います！


================================================================================
1. url_for() の基本構文
================================================================================

【正しい構文】

url_for('Blueprint名.関数名')
         └───┬──┘ └──┬──┘
        Blueprint名  関数名


【実際の例（profile.py から）】

# api/profile.py
profile_bp = Blueprint('profile', __name__, url_prefix='/api')
#                      └──┬───┘
#                   Blueprint名

@profile_bp.route('/user/profile', methods=['GET'])
#                 └──────┬──────┘
#                   ルートパス（url_for()では使わない！）
@jwt_required()
def get_authenticated_user_profile():
#   └───────────┬────────────────┘
#            関数名（これを使う！）
    return jsonify({'message': 'プロフィール取得'})


【url_for() の正しい使い方】

from flask import url_for

# ✅ 正しい
url = url_for('profile.get_authenticated_user_profile')
#             └──┬──┘ └──────────┬─────────────────┘
#          Blueprint名      関数名

print(url)  # → /api/user/profile


# ❌ 間違い
url = url_for('profile_bp.profile')  # ← エラー
url = url_for('profile./user/profile')  # ← エラー
url = url_for('/api/user/profile')  # ← エラー


================================================================================
2. なぜ関数名を使うのか？
================================================================================

【理由】

Flask は内部で「endpoint」という仕組みを使っています。
endpoint は「Blueprint名.関数名」という形式です。


【endpoint の例】

@profile_bp.route('/user/profile')
def get_authenticated_user_profile():
    pass

→ endpoint: 'profile.get_authenticated_user_profile'
             └──┬──┘ └──────────┬─────────────────┘
          Blueprint名         関数名


【url_for() と endpoint の関係】

url_for() は endpoint を引数に取る関数です。

url_for('profile.get_authenticated_user_profile')
         └──────────────┬───────────────────────┘
                    endpoint


Flask は endpoint からルートを逆引きする:

endpoint: 'profile.get_authenticated_user_profile'
    ↓
Blueprint: 'profile' → url_prefix='/api'
    ↓
関数: get_authenticated_user_profile → @route('/user/profile')
    ↓
最終的なURL: /api/user/profile

3. 実際の例
================================================================================

【例1: profile.py の場合】

# api/profile.py (13-18行目)
profile_bp = Blueprint('profile', __name__, url_prefix='/api')

@profile_bp.route('/user/profile', methods=['GET'])
@jwt_required()
def get_authenticated_user_profile():
    """JWT認証済みユーザーのプロフィール情報を取得"""
    # ... プロフィール取得処理


【url_for() の使い方】

from flask import url_for

# ✅ 正しい
url = url_for('profile.get_authenticated_user_profile')
print(url)  # → /api/user/profile

# ❌ 間違い
url = url_for('profile.profile')  # ← 関数名が違う
# BuildError: Could not build url for endpoint 'profile.profile'


【別のファイルから使う場合】

# api/auth.py
from flask import url_for

@auth_bp.route('/login', methods=['POST'])
def login():
    # ログイン成功後、プロフィールページのURLを返す
    profile_url = url_for('profile.get_authenticated_user_profile')

    return jsonify({
        'message': 'ログイン成功',
        'redirect_url': profile_url  # /api/user/profile
    })


【例2: 複数のルートがある場合】

# api/profile.py
profile_bp = Blueprint('profile', __name__, url_prefix='/api')

@profile_bp.route('/user/profile', methods=['GET'])
def get_authenticated_user_profile():
    """プロフィール取得"""
    pass

@profile_bp.route('/user/profile', methods=['PUT'])

    pass

@profile_bp.route('/user/profile/image', methods=['POST'])

    """プロフィール画像アップロード"""

【各関数への url_for()】

# プロフィール取得

# → /api/user/profile

# プロフィール更新

# → /api/user/profile

# プロフィール画像アップロード
url_for('profile.upload_profile_image')
# → /api/user/profile/image

5. よくある間違い
================================================================================

【間違い1: ルートパスを使う】

❌ 間違い
────────────────────────────────────────
@profile_bp.route('/user/profile')
def get_profile():
    pass

# url_for()
url_for('/user/profile')  # ← ルートパスは使えない
# BuildError: Could not build url for endpoint '/user/profile'


✅ 正しい
────────────────────────────────────────
url_for('profile.get_profile')


【間違い2: Blueprint の変数名を使う】

❌ 間違い
────────────────────────────────────────
profile_bp = Blueprint('profile', __name__, url_prefix='/api')
#  └──┬──┘            └──┬───┘
#  変数名           Blueprint名

@profile_bp.route('/user/profile')
def get_profile():
    pass

# url_for()
url_for('profile_bp.get_profile')  # ← 変数名は使えない
# BuildError: Could not build url for endpoint 'profile_bp.get_profile'


✅ 正しい
────────────────────────────────────────
url_for('profile.get_profile')  # ← Blueprint名を使う


【間違い3: 関数名を省略】

❌ 間違い
────────────────────────────────────────
@profile_bp.route('/user/profile')
def get_profile():
    pass

# url_for()
url_for('profile')  # ← 関数名がない
# BuildError: Could not build url for endpoint 'profile'


✅ 正しい
────────────────────────────────────────
url_for('profile.get_profile')


【間違い4: URL を直接使う】

❌ 悪い例（ハードコーディング）
────────────────────────────────────────
return jsonify({
    'redirect_url': '/api/user/profile'  # ← ハードコーディング
})

問題点:
  • url_prefix を変更したら動かなくなる
  • タイポしやすい
  • 保守性が低い


✅ 良い例（url_for()を使う）
────────────────────────────────────────
from flask import url_for

return jsonify({
    'redirect_url': url_for('profile.get_authenticated_user_profile')
})

メリット:
  ✓ url_prefix を変更しても自動で追従
  ✓ タイポしにくい（エラーが出る）
  ✓ 保守性が高い


================================================================================
6. url_for() の高度な使い方
================================================================================

【パラメータ付きURL】

# api/users.py
@users_bp.route('/users/<int:user_id>', methods=['GET'])
def get_user(user_id):
    """特定ユーザー取得"""
    pass


# url_for()
url = url_for('users.get_user', user_id=123)
#                               └────┬────┘
#                            パラメータを渡す

print(url)  # → /api/users/123


【複数パラメータ】

# api/items.py
@items_bp.route('/items/<int:item_id>/images/<int:image_id>')
def get_item_image(item_id, image_id):
    pass


# url_for()
url = url_for('items.get_item_image', item_id=5, image_id=3)
print(url)  # → /api/items/5/images/3


【クエリパラメータ】

# api/users.py
@users_bp.route('/users', methods=['GET'])
def get_users():
    page = request.args.get('page', 1)
    limit = request.args.get('limit', 10)
    pass


# url_for()
url = url_for('users.get_users', page=2, limit=20)
#                                 └────┬─────┘
#                            クエリパラメータとして追加

print(url)  # → /api/users?page=2&limit=20


【_external=True で完全なURLを生成】

# 相対URL（デフォルト）
url = url_for('profile.get_authenticated_user_profile')
print(url)  # → /api/user/profile


# 絶対URL
url = url_for('profile.get_authenticated_user_profile', _external=True)
print(url)  # → http://localhost:5001/api/user/profile


# HTTPSで生成
url = url_for('profile.get_authenticated_user_profile',
              _external=True,
              _scheme='https')
print(url)  # → https://localhost:5001/api/user/profile


【_method でHTTPメソッドを指定】

# 同じURLでもメソッドが違う場合
@profile_bp.route('/user/profile', methods=['GET'])
def get_profile():
    pass

@profile_bp.route('/user/profile', methods=['PUT'])
def update_profile():
    pass


# GET用
url = url_for('profile.get_profile')
print(url)  # → /api/user/profile

# PUT用
url = url_for('profile.update_profile')
print(url)  # → /api/user/profile

# 注意: url_for()はURLを生成するだけで、メソッドは指定できない

7. 実践例
================================================================================

【例1: ログイン成功後のリダイレクト】

# api/auth.py
from flask import url_for, jsonify

@auth_bp.route('/login', methods=['POST'])
def login():
    email = request.json.get('email')
    password = request.json.get('password')

    # ログイン処理
    if authenticate(email, password):
        # プロフィールページのURLを返す
        profile_url = url_for('profile.get_authenticated_user_profile')

        return jsonify({
            'success': True,
            'redirect_url': profile_url  # /api/user/profile
        })
    else:
        return jsonify({'success': False}), 401


【例2: メールに含めるリンク】

# api/auth.py
from flask import url_for

@auth_bp.route('/register', methods=['POST'])
def register():
    email = request.json.get('email')

    # 確認リンクを生成（絶対URL）
    confirm_url = url_for('auth.confirm_email',
                         token=generate_token(email),
                         _external=True)

    # メール送信
    send_email(
        to=email,
        subject='メールアドレス確認',
        body=f'以下のリンクをクリックしてください: {confirm_url}'
        # http://localhost:5001/api/confirm?token=...
    )

    return jsonify({'message': '確認メールを送信しました'})


【例3: API レスポンスにリンクを含める】

# api/items.py
from flask import url_for, jsonify

@items_bp.route('/items', methods=['GET'])
def get_items():
    with get_db_connection() as conn:
        cursor = conn.cursor(dictionary=True)
        cursor.execute("SELECT * FROM items")
        items = cursor.fetchall()
        cursor.close()

    # 各アイテムに詳細URLを追加
    for item in items:
        item['detail_url'] = url_for('items.get_item_detail',
                                      item_id=item['item_id'])

    return jsonify({'items': items})

# レスポンス例:

#   "items": [

#       "title": "商品1",
#       "detail_url": "/api/items/1"
#     },
#     {
#       "item_id": 2,
#       "title": "商品2",
#       "detail_url": "/api/items/2"
#     }

# }

    """キーワードでendpointを検索"""

9. まとめ
================================================================================

【url_for() の正しい構文】

url_for('Blueprint名.関数名')

例:
  profile_bp = Blueprint('profile', __name__, url_prefix='/api')

  @profile_bp.route('/user/profile', methods=['GET'])
  def get_authenticated_user_profile():
      pass

  # url_for()
  url_for('profile.get_authenticated_user_profile')
  #       └──┬──┘ └──────────┬─────────────────┘
  #    Blueprint名         関数名


【質問への回答】

質問: profile_bp.profile とすると アクセスできる？

回答: ❌ いいえ、それは間違いです

理由:
  • url_for() の引数は 'Blueprint名.関数名'
  • 'profile_bp' は変数名なので使えない
  • 'profile' はルートパスではなく関数名を使う

正しい使い方:
  url_for('profile.get_authenticated_user_profile')
  #       └──┬──┘ └──────────┬─────────────────┘
  #    Blueprint名   実際の関数名（profile.py 18行目）


【重要ポイント】

✓ url_for('Blueprint名.関数名')
✓ ルートパス('/user/profile')ではなく関数名を使う
✓ Blueprint変数名(profile_bp)ではなくBlueprint名('profile')を使う
✓ パラメータはキーワード引数で渡す
✓ _external=True で絶対URLを生成
✓ ハードコーディングよりurl_for()を使う方が保守性が高い


【よくある間違い】

❌ url_for('profile_bp.get_profile')      # 変数名は使えない
❌ url_for('profile.profile')             # 関数名が間違い
❌ url_for('profile./user/profile')       # ルートパスは使えない
❌ url_for('/api/user/profile')           # URL直指定は使えない

✅ url_for('profile.get_authenticated_user_profile')  # 正しい
