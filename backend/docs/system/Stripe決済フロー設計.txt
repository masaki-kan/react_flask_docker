1. 要件
================================================================================

【お金の流れ】

購入者（Buyer）
    ↓ 支払い
僕らのヴィンテージ（プラットフォーム）
    ↓ 送金（手数料を引いた金額）
出品者（Seller / 申請された人）


【目的】
  ✓ 購入者から直接出品者に送金しない
  ✓ プラットフォームが一旦受け取る
  ✓ プラットフォームが手数料を差し引いて出品者に送金
  ✓ 手数料でプラットフォームの収益を確保


================================================================================
2. Stripe Connect の概要
================================================================================

【Stripe Connect とは？】

Stripe が提供する、マーケットプレイスやプラットフォームビジネス向けの
決済・送金の仕組み。

主な機能:
  ✓ プラットフォーム経由での決済
  ✓ 複数の出品者（Connected Accounts）を管理
  ✓ 自動的な送金・分配
  ✓ 手数料の徴収
  ✓ 返金処理


【類似サービスの例】

- メルカリ
- Airbnb
- Uber
- BASE
- STORES

これらは全て Stripe Connect や類似の仕組みを使用しています。


【Stripe Connect の3つのモデル】

1. Standard Accounts（標準アカウント）
   ────────────────────────────────────────
   • 出品者が自分でStripeアカウントを作成
   • プラットフォームは最小限の情報しか取得できない
   • 出品者が自分で税務処理を行う

2. Express Accounts（簡易アカウント）★ 推奨
   ────────────────────────────────────────
   • プラットフォームが出品者のアカウント作成を簡略化
   • 出品者は最小限の情報入力で開始できる
   • プラットフォームが一部の管理を代行
   • バランスが取れたモデル

3. Custom Accounts（カスタムアカウント）
   ────────────────────────────────────────
   • プラットフォームが全てを管理
   • 出品者はStripeを意識しない
   • プラットフォームの責任が大きい
   • 実装が複雑


【推奨: Express Accounts】

理由:
  ✓ 実装が比較的簡単
  ✓ 出品者の登録がスムーズ
  ✓ プラットフォームとしての柔軟性が高い
  ✓ 税務処理はStripeが一部サポート

3. お金の流れの詳細
================================================================================

【パターン1: Direct Charges（直接チャージ）】

購入者
  ↓ ¥5,000 を支払い
Stripe
  ↓ Stripeの決済手数料を引く（約¥145）
  ↓ ¥4,855 がプラットフォームに入金
プラットフォーム（僕らのヴィンテージ）
  ↓ プラットフォーム手数料を引く（例: ¥485 = 10%）
  ↓ ¥4,370 を出品者に送金
出品者（Seller）
  ↓ Stripe送金手数料（約¥25）
  ↓ ¥4,345 を受け取り


【パターン2: Destination Charges（推奨）】

購入者
  ↓ ¥5,000 を支払い
Stripe
  ↓ Stripeの決済手数料を引く（約¥145）
  ↓ 自動で振り分け:
  ├─ ¥485（10%）→ プラットフォーム
  └─ ¥4,370（90%）→ 出品者のアカウント
  ↓
プラットフォーム: ¥485
出品者: ¥4,370（手数料なしで自動入金）


【パターン3: Separate Charges and Transfers】

購入者
  ↓ ¥5,000 を支払い
Stripe
  ↓ Stripeの決済手数料を引く（約¥145）
  ↓ ¥4,855 がプラットフォームに入金
プラットフォーム
  ↓ 後で手動で送金API実行
  ↓ ¥4,370 を出品者に送金
出品者
  ↓ ¥4,370 を受け取り


【推奨: Destination Charges】

理由:
  ✓ 自動で振り分けされる
  ✓ 送金手数料がかからない
  ✓ 実装がシンプル
  ✓ 即座に出品者のアカウントに入金

4. 手数料の詳細
================================================================================

【Stripe の決済手数料（日本）】

基本手数料:
  3.6% + ¥0

例:
  • ¥1,000 の決済: ¥36
  • ¥5,000 の決済: ¥180
  • ¥10,000 の決済: ¥360


【Stripe Connect の追加手数料】

✓ 追加手数料なし

Stripe Connect を使っても、基本的な決済手数料（3.6%）のみで、
追加の手数料は発生しません。


【送金手数料（Transferの場合）】

Separate Charges and Transfers を使う場合のみ:
  • 国内送金: 無料
  • 国外送金: 有料

Destination Charges を使う場合:
  • 送金手数料なし（自動振り分けのため）


【プラットフォーム手数料（あなたが設定）】

プラットフォームの収益として、任意の手数料を設定できます。

一般的な手数料率:
  • メルカリ: 10%
  • BASE: 3% + ¥40
  • STORES: 5%
  • Airbnb: 3-15%

推奨:
  • 10%（¥10,000 の取引なら¥1,000）
  • または 3.6% + 固定額


【手数料の計算例】

┌────────────────────────────────────────────────────────┐
│ 例: ¥5,000 の商品を購入                                │
├────────────────────────────────────────────────────────┤
│ 購入者が支払う金額: ¥5,000                             │
│                                                        │
│ Stripe決済手数料: ¥5,000 × 3.6% = ¥180                │
│ → プラットフォームに入金: ¥4,820                       │
│                                                        │
│ プラットフォーム手数料（10%）: ¥5,000 × 10% = ¥500    │
│ → プラットフォームの収益: ¥500                         │
│                                                        │
│ 出品者への送金: ¥4,820 - ¥500 = ¥4,320                │
│ → 出品者が受け取る金額: ¥4,320                         │
└────────────────────────────────────────────────────────┘


別の計算方法（Destination Charges）:
┌────────────────────────────────────────────────────────┐
│ 購入者が支払う金額: ¥5,000                             │
│                                                        │
│ Stripe決済手数料: ¥180（自動で引かれる）              │
│                                                        │
│ Application Fee（プラットフォーム手数料）: ¥500       │
│ → プラットフォームに自動入金: ¥500                     │
│                                                        │
│ 出品者のアカウントに自動入金: ¥4,320                   │
│ （¥5,000 - ¥180 - ¥500）                              │
└────────────────────────────────────────────────────────┘

5. Destination Charges の実装例
================================================================================

【フロー】

[1] 出品者のStripe Connected Account作成
    ↓
[2] 購入者が決済
    ↓
[3] Stripeが自動で振り分け
    ├─ プラットフォーム手数料 → プラットフォーム
    └─ 残額 → 出品者のアカウント
    ↓
[4] 出品者は銀行口座に出金


【バックエンド実装（Python）】

import stripe

stripe.api_key = 'sk_test_...'

# [1] 出品者のConnected Account作成
def create_connected_account(user_email):
    """出品者のStripeアカウント作成"""
    account = stripe.Account.create(
        type='express',  # Express Account
        country='JP',
        email=user_email,
        capabilities={
            'card_payments': {'requested': True},
            'transfers': {'requested': True},
        },
    )
    return account.id  # acct_xxxxx


# [2] アカウント登録リンク生成
def create_account_link(account_id):
    """出品者がStripe情報を登録するリンク"""
    account_link = stripe.AccountLink.create(
        account=account_id,
        refresh_url='https://yoursite.com/reauth',
        return_url='https://yoursite.com/return',
        type='account_onboarding',
    )
    return account_link.url


# [3] 決済実行（Destination Charges）
def create_purchase_payment(amount, seller_account_id, platform_fee_rate=0.10):
    """
    購入決済を実行

    amount: 購入金額（円）
    seller_account_id: 出品者のStripe Account ID
    platform_fee_rate: プラットフォーム手数料率（デフォルト10%）
    """
    # プラットフォーム手数料を計算
    platform_fee = int(amount * platform_fee_rate)

    # PaymentIntent作成
    payment_intent = stripe.PaymentIntent.create(
        amount=amount,  # ¥5,000 なら 5000
        currency='jpy',
        payment_method_types=['card'],

        # Destination Charges の設定
        application_fee_amount=platform_fee,  # プラットフォーム手数料
        transfer_data={
            'destination': seller_account_id,  # 出品者のアカウント
        },
    )

    return payment_intent


# 使用例
payment_intent = create_purchase_payment(
    amount=5000,  # ¥5,000
    seller_account_id='acct_xxxxx',  # 出品者のアカウントID
    platform_fee_rate=0.10  # 10%
)

# この決済が完了すると:
# - Stripe手数料 ¥180 が自動で引かれる
# - プラットフォーム手数料 ¥500 がプラットフォームに入る
# - 残り ¥4,320 が出品者のアカウントに入る

3. 急ぎの場合は Instant Payout を利用

8. 送金のタイミング
================================================================================

【オプション1: 即座に送金（Destination Charges）】

取引完了と同時:
  ✓ 決済と同時に出品者のアカウントに入金
  ✓ 自動で振り分けられる
  ✓ プラットフォームは何もしなくて良い

リスク:
  ✗ 返金時の処理が複雑
  ✗ 紛争時の対応が難しい


【オプション2: 商品到着後に送金】

商品到着を確認してから:
  ✓ 購入者が「受け取り完了」を押してから送金
  ✓ トラブル時に返金しやすい
  ✓ 安全性が高い

デメリット:
  ✗ 実装が複雑
  ✗ 出品者への入金が遅れる


【オプション3: エスクロー（推奨）】

お金をプラットフォームで一時的に保管:
  1. 購入時に決済
  2. お金をプラットフォームで保管
  3. 商品到着後に送金

実装:
  • Destination Charges の代わりに Direct Charges
  • 商品到着確認後に Transfer API で送金


【推奨: オプション3（エスクロー）】

理由:
  ✓ 購入者を保護できる
  ✓ トラブル時に返金しやすい
  ✓ プラットフォームとしての信頼性が高い

9. エスクロー実装例
================================================================================

【フロー】

[1] 購入者が決済
    ↓ お金はプラットフォームに入る
[2] 出品者が発送
    ↓
[3] 購入者が「受け取り完了」
    ↓ プラットフォームから出品者に送金
[4] 出品者がお金を受け取る


【実装コード】

# [1] 決済実行（Direct Charge）
def create_purchase_payment_escrow(amount, trade_id):
    """購入決済（エスクロー）"""
    payment_intent = stripe.PaymentIntent.create(
        amount=amount,
        currency='jpy',
        payment_method_types=['card'],
        metadata={
            'trade_id': trade_id,
            'type': 'purchase'
        }
    )
    return payment_intent


# [2] 商品到着後、出品者に送金
def transfer_to_seller(trade_id, seller_account_id, amount, platform_fee_rate=0.10):
    """出品者に送金"""
    # プラットフォーム手数料を引く
    platform_fee = int(amount * platform_fee_rate)
    transfer_amount = amount - platform_fee

    # 送金実行
    transfer = stripe.Transfer.create(
        amount=transfer_amount,
        currency='jpy',
        destination=seller_account_id,
        metadata={
            'trade_id': trade_id,
            'platform_fee': platform_fee
        }
    )
    return transfer


# 使用例
# 購入時
payment = create_purchase_payment_escrow(
    amount=5000,
    trade_id=123
)

# 商品到着後
transfer = transfer_to_seller(
    trade_id=123,
    seller_account_id='acct_xxxxx',
    amount=5000,
    platform_fee_rate=0.10
)


【Stripe手数料について】

エスクローの場合:
  • 決済時: 3.6% + ¥0
  • 送金時: 無料（国内）

合計: 3.6% のみ（Destination Chargesと同じ）

10. 返金処理
================================================================================

【返金が必要な場合】

- 商品が届かない
- 商品が説明と違う
- 商品が破損している
- 取引がキャンセルされた


【Destination Charges の場合】

# 全額返金
refund = stripe.Refund.create(
    payment_intent='pi_xxxxx',
    refund_application_fee=True,  # プラットフォーム手数料も返金
)

結果:
  • 購入者に ¥5,000 返金
  • プラットフォームの ¥500 も返金される
  • Stripe手数料 ¥180 は返金されない（Stripeが保持）


【エスクローの場合】

送金前:
  # 決済を返金
  refund = stripe.Refund.create(
      payment_intent='pi_xxxxx',
  )

  結果: 購入者に全額返金

送金後:
  # 1. 出品者から返金してもらう（Reverse Transfer）
  reversal = stripe.Transfer.create_reversal(
      'tr_xxxxx',
      amount=4320,  # 出品者が受け取った金額
  )

  # 2. 購入者に返金
  refund = stripe.Refund.create(
      payment_intent='pi_xxxxx',
  )


【部分返金】

# 半額返金の例
refund = stripe.Refund.create(
    payment_intent='pi_xxxxx',
    amount=2500,  # ¥5,000 の半額
)
